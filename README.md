# Taller de Programación Orientada a Objetos

Este proyecto corresponde al Taller de la Clase N.º 3 de la materia **Programación Avanzada**.

## Objetivos

1. Entender y comprender ejercicios prácticos de Programación Orientada a Objetos.
2. Trabajar en equipos colaborativos.
3. Utilizar un IDE a elección para el desarrollo de código Python.
4. Aplicar conceptos básicos de Python 3 y POO.
5. Implementar el uso básico de Git y GitHub:
   - Crear un repositorio.
   - Subir archivos del taller.
   - Invitar a compañeros de grupo y al docente (felipemoralesquerol) como colaboradores.

## Contenido

Este repositorio contiene las soluciones a los siguientes ejercicios:
- Ejercicio 2: Clase `Punto`
- Ejercicio 3: Clase `Linea`
- Ejercicio 4: Clase `Cancion`
- Ejercicio 5: Clase `Libro` y `Persona`
